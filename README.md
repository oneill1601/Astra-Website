# Astra Website

Estructura organizada del sitio de Astra.

- `css/`: estilos separados por página y animaciones compartidas.
- `js/`: lógica JavaScript separada por pantalla.
- `dashboard/`: páginas del dashboard.
- `assets/`: recursos estáticos.

La reorganización mantiene el HTML y comportamiento existentes; no conecta todavía el dashboard con la API del bot.
