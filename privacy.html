Política de Privacidad de Astra

Última actualización: 26 de agosto de 2026

1. Información general

Astra es una aplicación de Discord que ofrece funciones sociales, de entretenimiento, economía y utilidades para usuarios y servidores.

2. Información que puede procesarse

Astra puede procesar identificadores necesarios para proporcionar sus funciones, como el ID de usuario de Discord, ID de servidor, ID de canales y datos de configuración.

Según las funciones utilizadas, pueden almacenarse datos de progreso, estadísticas, relaciones sociales, matrimonios, economía, inventarios, empresas y configuraciones del servidor.

3. Uso de la información

La información se utiliza para proporcionar, mantener y mejorar las funciones de Astra, guardar el progreso y aplicar las configuraciones solicitadas por usuarios o administradores.

4. Mensajes y contenido

Astra puede acceder al contenido estrictamente necesario para determinadas funciones que requieren detectar comandos, respuestas o interacciones. No se pretende almacenar conversaciones privadas completas como parte del funcionamiento normal del servicio.

5. Compartición de datos

Astra no vende datos personales ni comparte datos con terceros con fines publicitarios. La información puede ser procesada por los servicios técnicos necesarios para operar la aplicación.

6. Conservación y eliminación

Los datos se conservan mientras sean necesarios para proporcionar las funciones correspondientes. Cuando sea técnicamente posible, los usuarios pueden solicitar la eliminación de los datos asociados a ellos.

7. Seguridad

Se aplican medidas razonables para proteger la información almacenada y limitar el acceso a los datos a las funciones que los necesitan.

8. Cambios

Esta política puede actualizarse cuando Astra incorpore nuevas funciones o cambien sus prácticas de tratamiento de datos. La fecha de actualización se indicará en esta página.

9. Contacto

Para consultas relacionadas con privacidad o eliminación de datos, utiliza el canal oficial de soporte de Astra.
